Reinforcement Learning
Coding Tutorials

Practical notebooks for building RL environments, estimating value functions, and learning control policies. Choose a module and open its notebook in Google Colab.

No local installation required.
The notebooks can be opened directly in Colab. Use File → Save a copy in Drive before editing so your work is saved to your own account.

Interactive Tutorials

Each module has an exercise notebook and a separate reference solution. The solution passcode will be provided in class.

Instructions for Students

  1. Open a notebook. Choose a module and select Open in Colab.
  2. Save your own copy. In Colab, select File → Save a copy in Drive.
  3. Work through the cells. Run each section in order, complete the TODOs, and review training results and visualizations.

Course Repository

The exercise and solution notebooks are stored in the top-level RL-basics and policy-gradient folders. When opened in Google Colab, the notebooks automatically load their supporting files from tutorial-utk-main in the same course repository.
